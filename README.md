# 经文故事 · JWGS

将《心经》《金刚经》《道德经》《清静经》四部经典转化为现代现实主义短故事的写作项目。

每个创作单元遵循统一的结构：

```
经文原文  →  核心要义  →  现实故事  →  善知识  →  现实实践
```

不是讲经，不是说理，是用普通人的真实困境，让经文自己显出重量。

## 创作规范要点

- **单一输出**：只输出发布版一个文件，不记录研究过程
- **零破折号**：所有故事破折号（——）使用数必须为 0
- **零省略号**：所有故事省略号（……）使用数必须为 0
- **标题硬性规则**：标题必须直接取自经文原文，或经文回答的核心问题
- **现实主义**：写普通人的真实困境，不写玄学、不说道理、不讲佛法
- **AI 文感禁令**：避免一切机器化叙事套路

完整规范见 [SKILL.md](SKILL.md)。
